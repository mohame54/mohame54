#### 🧠 Proofbusters at SemEval-2026 Task 11
**SemEval-2026 · ACL Anthology · First author**

Neuro-symbolic syllogistic reasoning. We abstract natural-language arguments into set-theoretic notation before LLM inference, so the model cannot rely on whether a conclusion *sounds* believable. Reached **98.95% accuracy** with a content-bias (TCE) of **2.13** on the English sub-task.

*M. Ayman, K. Marzouk, A. Mashaly, A. Hereiz*

`LLMs` `Reasoning` `Belief Bias` `Neuro-Symbolic`
